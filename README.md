# «Море Котиков»

Адаптивный бренд-лендинг самарского котокафе-антикафе «Море Котиков». Он знакомит посетителя с форматом и атмосферой места и оставляет три прямых действия без вымышленной формы бронирования: позвонить, написать в социальную сеть или построить маршрут.

- Адрес после деплоя: [nnfall.github.io/seaofcats](https://nnfall.github.io/seaofcats/)
- Репозиторий: [NNFall/seaofcats](https://github.com/NNFall/seaofcats)

## Происхождение изображений

Документальные фотографии показывают реальное заведение и реальных животных. Для каждого файла в [`src/assets/images/SOURCES.md`](src/assets/images/SOURCES.md) сохранены локальное имя, исходный URL, дата получения, классификация и статус прав. Публичная доступность изображения сама по себе не означает разрешение на повторное использование: перед коммерческим использованием владелец проекта должен подтвердить право использования либо заменить изображение.

Сгенерированная графика допустима только как декоративный фон или орнамент. Для неё в реестре нужно указывать инструмент, дату и полный промпт; она никогда не маркируется как фотография пространства или котиков. Оптимизация и перекодирование файла не отменяют запись о первоисточнике.

## Локальный запуск

Локально нужен Node.js 22.12 или новее и npm; CI использует Node.js 24. Все команды выполняются из корня репозитория.

| Команда | Назначение |
| --- | --- |
| `npm ci` | Воспроизводимая установка зависимостей из `package-lock.json` |
| `npm run dev` | Сервер разработки |
| `npm run check` | Проверка Astro и TypeScript |
| `npm run test:install` | Установка Chromium для Playwright |
| `npm run test:unit` | Модульные и компонентные тесты Vitest |
| `npm run test:e2e` | Браузерные сценарии Playwright |
| `npm run test` | Полный набор тестов: Vitest и Playwright |
| `npm run build` | Статическая production-сборка в `dist/` |
| `npm run preview` | Локальный просмотр production-сборки |

Сервер разработки и preview используют один адрес: [http://127.0.0.1:4327/seaofcats/](http://127.0.0.1:4327/seaofcats/). Перед первым запуском браузерных тестов выполните `npm run test:install`.

## Матрица проверок

| Область | Команда или viewport | Что проверяется |
| --- | --- | --- |
| Типы и Astro | `npm run check` | Строгий TypeScript, корректность Astro-компонентов |
| Поведение | `npm run test:unit` | Проверенные факты, навигация, меню и управление фотолентой |
| Desktop reference | 1672×941 | Композиция шести сцен, типографика, кадрирование, отсутствие overflow |
| Desktop wide | 1920×1080 | Дополнительная 16:9 проверка hero, header и арочной фотографии |
| Desktop | 1440×900 | Адаптация сетки и отсутствие горизонтального overflow |
| Tablet | 1024×768 | Переходная компоновка, навигация и доступность действий |
| Mobile | 390×844 | Мобильное меню, фотолента, sticky CTA и отсутствие перекрытий |
| Narrow mobile | 320×568 | Минимальная ширина, зоны управления не меньше 44 px, отсутствие overflow |
| Browser flows | `npm run test:e2e` | Якорная навигация, публичные ссылки, WCAG-проверка и responsive overflow; клавиатурные сценарии фотоленты дополнительно покрыты Vitest |

Эталонные визуальные снимки требуются для 1672×941, 390×844 и 320×568; перед релизом вручную просматриваются все пять viewport из таблицы. Права на документальные кадры остаются отдельным release-check владельца контента, потому что исходные публичные карточки не сообщают автора или лицензию.

Последние снимки из встроенного Browser сохраняются в [`artifacts/screenshots/`](artifacts/screenshots/): desktop 1672×941, mobile 390×844, narrow mobile 320×568 и отдельная сцена фотоленты.

## Деплой

Astro собирает статический сайт с base path `/seaofcats/`. Workflow [`.github/workflows/pages.yml`](.github/workflows/pages.yml) запускается при push в `main` и вручную через `workflow_dispatch`. На Node.js 24 он последовательно выполняет `npm ci`, `npm run check`, устанавливает Chromium, запускает `npm run test` и `npm run build`, загружает каталог `dist/` официальным Pages artifact action и публикует его через официальный Pages deploy action.

В настройках репозитория **Settings → Pages → Build and deployment → Source** должен быть выбран **GitHub Actions**. Деплой выполняется только после успешного завершения всех проверок и сборки.

GitHub Project Pages публикует этот репозиторий в подпапке, поэтому `robots.txt` доступен по `/seaofcats/robots.txt`, а не в корне `nnfall.github.io`. По RFC 9309 он не заменяет корневой файл хоста; для индексирования сайт также отдаёт canonical URL и sitemap. Управлять правилами для всего хоста можно только через корневой сайт `NNFall.github.io`.
